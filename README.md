Street Heat is an original open-world crime game set in Meridian Bay: explore the city on foot and by car, steal cars, outrun the police through a five-star wanted system, and run a four-mission story — with traffic, pedestrians, a HUD and a minimap. Vanilla JavaScript and canvas, no libraries, no network.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
